## 📱 О приложении

**AnimeLib** объединяет удобство WebView-навигации по каталогу сайта animelib.org и встроенного нативного видеоплеера. Приложение автоматически подтягивает данные авторизации, закладки и историю просмотров, адаптируя веб-сервис под мобильные устройства.

---

## ✨ Основные возможности

* 🌐 **Интеграция с animelib.org**: Полный доступ к веб-версии сайта, личным спискам и каталогу.
* 🎥 **Кастомный видеоплеер**:
  * **Выбор CDN-серверов**: Быстрое переключение серверов (Основной, Резервный 1, Резервный 2).
  * **Выбор вариантов и озвучек**: Переключение плееров (AnimeLib, Kodik, Libria) и озвучек/субтитров.
  * **Пропуск опенингов и эндингов**: Быстрый пропуск с настраиваемыми интервалами.
  * **Эффект подсветки (Ambient Light)**: Динамическая адаптивная подсветка фона под цвет кадра.
  * **Управление жестами**: Свайпы по экрану для регулировки громкости, яркости и перемотки.
  * **Режим «Картинка в картинке» (PiP)**: Фоновый просмотр видео во время работы с другими приложениями.
* ⬇️ **Менеджер загрузок**:
  * Скачивание эпизодов во внутреннее и внешнее хранилище (`MediaStore.Downloads/AnimeLIB`).
  * Фоновое управление очередью и отслеживание прогресса скачивания.
* 💬 **Интерактивные комментарии**:
  * Просмотр и написание комментариев к эпизодам с поддержкой спойлеров и форматирования.
* 🔖 **Синхронизация и оффлайн-режим**:
  * Автоматическая синхронизация списков просмотра (Смотрю, В планах, Просмотрено) с кешированием закладок.
* 🎨 **Темы и персонализация**:
  * Поддержка тёмной и светлой темы с кастомизацией элементов управления.

## 🛠 Технические характеристики

### Требования
* **Минимальная версия Android**: 10.0 (API Level 29)
* **Целевая версия Android**: 15.0 (API Level 35)
* **Язык разработки**: Java 11
* **Архитектурный подход**: MVVM + Android Architecture Components

### Используемый стек
* **UI & Layouts**: Material Components, ViewBinding, Custom Views
* **Media Player**: AndroidX Media3 (ExoPlayer, HLS, UI, OkHttp Datasource)
* **Database & Persistence**: Room Database (Entity, DAO, Migrations)
* **Network & API**: OkHttp 4, Gson, JSoup (для парсинга HTML и обработки ссылок)
* **WebView Integration**: Custom WebChromeClient, WebViewClient, JavaScript Bridge

## 🚀 Сборка и установка

### Предварительные требования
* **Android Studio** (Ladybug / Narwhal или более новая версия)
* **JDK 17** или выше (рекомендуется JDK 21)
* **Android SDK**: Build-Tools 35.0.0, SDK Platform 35

### Инструкция по сборке

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Fazer000/AnimeLib-Mobile.git
   cd AnimeLib-Mobile
   ```

2. Откройте проект в Android Studio и выполните синхронизацию Gradle.

3. Соберите Debug APK через консоль:
   ```bash
   ./gradlew assembleDebug
   ```
   *На Windows используйте `gradlew.bat`.*

4. Исполняемый файл APK будет находиться по пути:  
   `app/build/outputs/apk/debug/app-debug.apk`

## 📁 Структура проекта

```
app/src/main/
├── java/com/example/animelib/
│   ├── adapters/          # Адаптеры для списков (комментарии, варианты плееров, эпизоды)
│   ├── api/               # Взаимодействие с API animelib.org и Kodik
│   ├── data/              # Room DB (Entities, DAOs, DatabaseManager)
│   ├── dialogs/           # Диалоги и выбор тем
│   ├── managers/          # Менеджеры загрузок, жестов, плеера, звука
│   ├── models/            # DTO и POJO модели ответа API
│   ├── services/          # Фоновые сервисы (DownloadService)
│   ├── settings/          # BottomSheets настроек плеера (скорость, качество, субтитры)
│   ├── ui/                # Компоненты UI, кастомный WebView, активности
│   ├── util/              # Вспомогательные утилиты и хелперы
│   ├── MainActivity.java  # Главный экран (WebView + навигация)
│   └── VideoPlayerActivity.java # Экран нативного видеоплеера
├── assets/
│   ├── js/                # JS-инъекции для перехвата событий и авторизации
│   └── html/              # Локальные HTML-шаблоны
└── res/                   # Макеты layouts, ресурсы drawables, значения values
```

## ⚙️ Конфигурация и авторизация

1. **Базовый URL**: По умолчанию используется `https://animelib.org`. В случае смены домена, URL можно настроить в приложении или через ресурсы `strings.xml` (`site_url`).
2. **Перехват токена авторизации**: Скрипт `assets/js/auth-handler.js` считывает токен авторизации из `localStorage` при входе пользователя на сайте и передаёт его нативному коду приложения для выполнения авторизованных API-запросов (списки, комментарии, прогресс просмотра).
